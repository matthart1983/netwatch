# Diagnose and coverage

Open Diagnose with `9` in the full view. Findings use measurements, baselines and rule evidence; optional AI commentary is separate.

A rule can be unmeasured, learning or stale. No findings does not prove health. [Rule coverage](@repo@/docs/diagnostic-coverage.md) distinguishes contracted and beta rules; default CLI outcomes do not treat every beta rule as authoritative.

Use the [Diagnose guide](@repo@/docs/DIAGNOSE.md) for bounded CLI runs, coverage, explicit experiments, episodes and sharing. Experiments send traffic and can include an upload test; read [[Configuration and Privacy]] before starting them.
