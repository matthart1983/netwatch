# Keyboard controls

The [context-aware key reference](@repo@/docs/REFERENCE.md#keyboard-controls) is the maintained keybinding list. Press `?` for help in the current view.

In the full view, `1`–`9` and `0` select tabs, `,` opens Settings and `V` changes view. On Packets, `c` starts/stops capture, `/` sets a display filter and `s` opens the selected stream.

`p` pauses UI-driven updates; it is not a guarantee that capture, background workers or outbound traffic stop. Use capture controls to stop capture, and quit the process to end the session. Modal and tab-specific actions take precedence over global shortcuts.
