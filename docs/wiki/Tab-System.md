# Tabs and views

In the full view: `1` Dashboard, `2` Connections, `3` Interfaces, `4` Packets, `5` Stats, `6` Topology, `7` Timeline, `8` Processes, `9` Diagnose, `0` Egress.

Insights is optional commentary within Diagnose, not a separate tab. The legacy `default_tab = "insights"` value aliases Diagnose.

Use `V` to cycle full/lite/dense or select `--view` at startup. Dense requires at least 130×44; lite is intended for smaller terminals. Keys can have different meanings in tabs, views and overlays; see [[Keyboard Controls]] and the [reference](@repo@/docs/REFERENCE.md#keyboard-controls).
